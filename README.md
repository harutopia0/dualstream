# DualStream (Enhanced Version)

- **Author:** harutopia0
- **Original Creator:** Deshan Nawanjana

## Description
**DualStream** is a powerful browser extension that enables seamless streaming with **dual subtitles** and **local audio replacement** on any HTML5 video player. Special thanks to Deshan Nawanjana for creating the original amazing platform.

## Features
- **Dual Subtitles**: Upload and display up to 2 subtitle files simultaneously (ASS, SRT, VTT) with full bilingual styling and positioning.
- **Audio Replacement Engine**: Replace HTML5 video audio directly from local MKV, MP4, WebM, MKA, MP3, AAC, FLAC, WAV, and Opus files.
- **Multi-track Audio Detection**: Automatically scans and lets you choose among multiple audio tracks (e.g. Japanese, English, Vietnamese dub).
- **Zero-Latency Seeking & Settle Sync**: Sample-accurate, instantaneous 0ms seeking with smooth micro-drift rate synchronization.
- **Buffer & Stream Modes**: Choose between high-precision in-memory Buffer Mode or lightweight Stream Mode for full-length movies.
- **Timing & Delay Adjustments**: Fine-tune subtitle sync and audio delay (in ms) on the fly.

## Installation & Setup

### Step 1: Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/harutopia0/dualstream
```

*(Note: If you do not have Git installed, click the green Code button on the GitHub repository page, select Download ZIP, and extract the downloaded archive).*

### Step 2: Load into Chrome

1. Open Google Chrome and navigate to: `chrome://extensions/`
2. Turn on **Developer mode** using the toggle switch in the top-right corner.
3. Click the **Load unpacked** button located in the top-left corner.
4. Select the folder containing this source code (the directory where `manifest.json` is located).

---

## How to Use

1. Click on the Extension icon on the Chrome toolbar to open **DualStream**.
2. **Subtitles tab**: Upload up to 2 subtitle files simultaneously for bilingual display.
3. **Audio tab**: Upload a local video or audio container to replace web video audio with your preferred dub/audio track.
4. **Timing tab**: Adjust timing offsets with repeatable ±100ms, ±500ms, and ±1s precision buttons.
5. **Settings tab**: Customize subtitle appearance, colors, fonts, and positions.
